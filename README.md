# Team Profile Generator

## Description

The Team Profile Generator is a Node.js command-line application that helps managers build a roster of their software engineering team. Using Inquirer to capture user input, it then generates a dynamic HTML page that displays a nicely formatted team roster complete with clickable email addresses and GitHub links.
